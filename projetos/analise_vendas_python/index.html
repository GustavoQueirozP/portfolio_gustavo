E-commerce — Vendas com Python

Voltar ao portfólio

Problema / pergunta

Como evoluem as vendas, quais países e clientes se destacam e como explorar previsão e inatividade de clientes?

Dados

data.csv; o README refere a base como E-Commerce Sales do Kaggle. O notebook utiliza transações com quantidade, preço unitário, data, país e identificador de cliente.

Fonte
Documentada no README do projeto; referência exata a confirmar.
Licença dos dados
Não documentada no projeto; confirmar as condições de reutilização na fonte. A licença do template não se aplica aos dados.
Período e volume
Não documentados no README. Conferir a versão dos arquivos antes de reportar o recorte e a contagem.

Pipeline

Leitura do CSV em ISO-8859-1; inspeção de ausências; remoção de registros sem CustomerID; conversão de identificadores e datas; cálculo de valores de venda e agregação diária.

Método

Rankings por país e cliente; previsão de 30 dias com Prophet; criação de perfil de clientes e classificação de churn com árvore de decisão.

Resultados

Análise em revisão

Os indicadores ainda precisam ser validados. Os 3–5 resultados numéricos do case serão apresentados após essa revisão.

Stack

Python · pandas · NumPy · matplotlib · seaborn · Prophet · scikit-learn · Jupyter

Limitações e próximos passos

Revisar devoluções e valores negativos, definição de churn, vazamento de informação e validação temporal. A previsão é um exercício exploratório e não uma estimativa validada para uso operacional.
